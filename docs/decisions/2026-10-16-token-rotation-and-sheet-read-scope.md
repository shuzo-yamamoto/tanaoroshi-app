# トークンの更新手順と、AIがスプレッドシートを読む範囲の制限

## 背景
- 2026-10-15、v1.5.1 の作業で部門IDを本番の商品マスタと照合するため、AI(Claude Code)が**Googleドライブのコネクタでスプレッドシート全体を読んだ**。このコネクタはファイル内の全シートの先頭部分をまとめて返すため、`settings` シートの**本番トークンが作業記録(会話)に入った**。ファイル・コミット・チャットへの記載はない(コミットに無いことは確認済み)。README 不具合ログ#6。
- トークンは全端末(4店舗・最大29台)の同期・提出の認証に使う共有の値で、設定リンク・店舗別QR・印刷用PDFにも入っている。入れ替えるには、作り直しから各端末の再設定までを抜けなく行う手順が要る。
- オーナー指示(2026-10-16): ①今後は `settings` シートを読まず、必要なシート・範囲だけを指定して読む。Drive経由で全体を読む方法は使わない。CLAUDE.md の絶対ルールに追記する。②次の棚卸の前にトークンを新しくする。管理者向けの手順書を作る。トークンの値はチャット・ファイルに書かず、管理者の手元で生成・入力する。

## 決定内容
- **読み取りの制限**: スプレッドシートを読むときは `settings` シートを読まない。`商品マスタ` など必要なシート・範囲だけを指定する(例: `gviz/tq` の `sheet=` と `select`)。Driveコネクタのファイル読み取りのように全体を返す方法は使わない。CLAUDE.md の絶対ルールと共通標準§4 #19 に記載。
- **トークンの更新手順**(検収手順書 ⓪-13・README 設計判断#30):
  - 生成: 管理者のPCの Windows PowerShell で、暗号用の乱数から**40文字(0-9・a-f)**を作り、**画面に出さずクリップボードへ**直接入れる。
  - 順番: 全店の提出済みを確認 → 新しいトークンでPCのアプリに入れ、設定リンク・QR・印刷用PDFを**先に**作る → `settings` シート B1(書式なしテキスト)を書き換える(この瞬間に切り替わる) → 各端末をQRで再設定・接続テスト → 後片付け(古い印刷物の回収・クリップボードの消去・テスト用コピーの確認)。
  - **GASの再デプロイ・git push は不要**(GASは要求のたびに `settings` のトークンを読む)。コードの変更もない。
  - QRは**オンラインのQR作成サイトを使わず**、PCの中で作る(リンクにトークンが入っているため)。

## 却下した案とその理由
- **トークンを `settings` シートから Apps Script のスクリプトプロパティへ移す** … AIが読む範囲の問題は読み方の制限で防げる。移すとGASの変更・再デプロイと、管理者がトークンを確認・変更する手順の作り直しが要り、今回の目的(早く安全に入れ替える)に対して大きすぎる。提案止まり。
- **アプリの設定画面に「設定リンクを貼り付けて適用」欄を足す**(iPhoneのホーム画面のアプリにQRの設定が入らない場合の対策) … 実機で問題が出るか未確認。手順 N-1 で確かめ、多数の端末で必要になった場合に相談する(仕様外の機能追加のため提案止まり)。
- **QRの作成をアプリ内で行う** … 2026-07-25 の運用方針(外部ツールでQR化)を変えない。CDN不使用で正しく動くエンコーダの用意と検証が要る(README 将来拡張の設計メモ)。
- **トークンを32文字の英数字(大文字・小文字・数字)にする** … 手入力が必要になったとき(N-5)に大文字・小文字・0とOの区別で打ち間違えやすい。40文字の16進数で160ビット相当あり、強さは足りる。
- **トークンを書き換えてからリンク・QR・PDFを作る** … その間、全端末が使えない時間が長くなる。先に作っておけば、切り替えから再設定までの時間を短くできる。

## 影響範囲
- コード(`js/` `gas/` `sw.js`)の変更なし。アプリの版は 1.5.1 のまま。
- 文書: README(不具合ログ#6・設計判断#30)・CLAUDE.md(絶対ルール2項目)・検収手順書 ⓪-13・`docs/qr/README.md`・共通標準§4 #19。
- 切り替えの瞬間から、古いトークンの端末は同期・提出・接続テストが「認証に失敗しました」になる。端末の棚卸データ・マスタは消えず、再設定のあと提出し直せる(2026-10-20 にローカルの擬似GASで、実際の `Code.gs` とアプリの画面を使って再現・確認。検収手順書 ⓪-13「切り替えの再現」)。
- 未確認: iPhoneでホーム画面に追加済みの端末で、QRで開いた設定がホーム画面のアプリにも入るか。手順 N-1 で実機(iPhone・Android 各1台)で確かめてから全台に進める。入らない場合は N-5(管理者が直接入力)で対応する。
- 負荷テスト用のコピー(⓪-11)は別のトークンで動くので影響しない。本番の古いトークンのままコピーしていた場合は手順 P-4 で直す。
