# docs/qr — 店舗別QRコードの置き場（コミットしない）

`操作ガイド.html` の最終ページに差し込む、店舗別QRコードの画像を置く場所です。

## 重要（セキュリティ）

このQRコードは **提出用トークンを含む設定リンク** をエンコードしたものです。
トークンが漏れると第三者がスプレッドシートに書き込めてしまうため、
**このフォルダの画像ファイルと、QR入りの印刷用PDFは Git にコミットしません**
（`.gitignore` で `docs/qr/*.png` と `docs/*.pdf` を除外済み）。

- 画像・完成PDFは **社内限り** で扱う（外部送信・公開しない）
- トークンを変更したら、QRコードを作り直す

## 置くファイル名（`操作ガイド.html` が参照する名前）

| ファイル名 | 店舗（拠点コード） |
|---|---|
| `gwh.png` | 本店（GWH） |
| `gws.png` | 京都精華大学店（GWS） |
| `gwk.png` | 京都美術工芸店（GWK） |
| `gwc.png` | 京都市立芸術大学店（GWC） |

各QRの中身は、その店舗の設定リンク（`…/#setup=1&gasUrl=…&token=…&loc=<コード>`）です。
アプリの「設定」タブ →「🔗 配布用の設定リンクを作る」で生成したURLを、
外部のQR作成ツールでQR化して、上記の名前で保存してください。

## 印刷用PDFの作り方（ローカル）

4枚の画像をこのフォルダに置いたあと、リポジトリ直下で:

```bash
"/c/Program Files/Google/Chrome/Application/chrome.exe" --headless --disable-gpu --no-pdf-header-footer --print-to-pdf="docs/操作ガイド_印刷用.pdf" "docs/操作ガイド.html"
```

生成された `docs/操作ガイド_印刷用.pdf` を印刷して各店舗に掲示してください（PDFはコミットされません）。
